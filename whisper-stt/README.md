# Local Whisper research archive

The active dictation implementation and setup guide are in the official
Omarchy plugin:
[`omarchy/plugins/nfragakis.whisper/`](../omarchy/plugins/nfragakis.whisper/README.md).

This directory retains the original benchmark and research notes. The model
weights, compiled `whisper.cpp` runtime, recordings, and machine-specific audio
settings belong under `~/.config/whisper-stt/` and remain outside git.
